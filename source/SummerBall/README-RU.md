# SummerBall 2.1 — SUMMER + SHULLER

Оба шара находятся в одном плагине. Целевая версия: Leaf / Paper 1.21.11, Java 21. Эта сборка не предназначена для 1.16.5 или 1.21.1.

## Установка

1. Остановить сервер. Сделать копию старого JAR SummerBall и папки plugins/SummerBall.
2. Убрать старый JAR SummerBall из plugins, установить SummerBall-2.1-Leaf-1.21.11.jar. Не оставлять две версии одновременно.
3. Существующий plugins/SummerBall/config.yml сохраняется. При отсутствии он создастся из встроенного конфига. Этот JAR собран из сохранённых исходников SummerBall_1.21.1_source.zip, содержащих обе сферы.
4. Перезапустить сервер, выдать новые предметы для проверки. После изменения атрибутов/описаний выдавать новые шары. Старые предметы со штатными PDC-метками должны распознаваться; автоматическое обновление их атрибутов не выполняется.

## Команды

- /summerball summer НИК — выдать Summer.
- /summerball shuller НИК — выдать Шуллер.
- /summerball reload — перечитать конфиг.
- Алиас: /sball.

Выдача: permission summerball.give, перезагрузка: summerball.reload. По умолчанию права доступны OP. Для применения держать шар во второй руке и нажать SHIFT; отпускание SHIFT не активирует способность.

## Что сохранено и исправлено

Сохранены настройки, ключи предметов, названия, текстуры, огненные эффекты и арбузный дождь Summer, иллюзия, облако, невидимость, скорость и сила Шуллера. Телепортация за цель по-прежнему выключена по умолчанию. Параметры берутся из config.yml.

Обновлены названия атрибутов для API 1.21.11. Сила Шуллера тратится только на ненулевой неотменённый ближний удар, а не на урон заклинаний. Исправлено восстановление прежней бесконечной силы.

Чистый урон Summer переведён с прямого setHealth на серверное событие урона: броня и сопротивление не уменьшают его, но плагины могут отменить событие. Поджигание выполняется только после принятого урона и отдельного неотменённого события поджигания. При нулевом уроне поджигание этим методом не выполняется. Креатив, наблюдатель, неуязвимые цели и игроки в мире с выключенным PVP не поражаются жаром.

Полная поддержка всех региональных/клановых правил не заявляется: отдельно проверить отрицательные эффекты Шуллера и опциональную телепортацию с установленными защитными плагинами.

## Проверки

Скомпилировано Java 21 против Leaf API 1.21.11 из предоставленного ядра №170. Изолированный запуск выполнен на официальном Leaf 1.21.11 №179 с Java 21.0.12.1. В этом тесте не запускались остальные плагины пользовательской сборки.

16 автоматических проверок прошли: включение плагина; создание двух голов, PDC, заполненные профили текстур и модификаторы во второй руке; ровно 5 единиц урона по цели с бронёй и сопротивлением; поджигание; отменённый урон не меняет здоровье и не поджигает; создание и удаление иллюзии; создание семи арбузов и очистка при выключении.

Тест подтвердил наличие текстурных свойств, но не визуальную загрузку скинов клиентом. Полный бой между реальными игроками, одноразовая сила в бою, совместимость со всеми защитами, старые предметы и отображение ресурспака требуют проверки на сервере. В изолированной среде были ограничения доступа к сервису ключей Mojang и предупреждения генератора тестового мира, не связанные с плагином.

Новый JAR собран из исходников: сторонние загрузчики и скачивание исполняемого кода в него не включены.

## Сборка исходников

Gradle с Java 21: gradle clean jar. Зависимость compileOnly: Paper API 1.21.11-R0.1-SNAPSHOT. Собранный JAR находится в build/libs. JDK, ядро сервера и сторонние библиотеки в исходный архив не включены.
