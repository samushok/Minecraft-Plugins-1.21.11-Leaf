# SantaBall 1.4 — Leaf 1.21.11 / Java 21

Плагин на основе последнего Santaball 1.3.1. Название плагина Santaball,
папка настроек и ключ предмета `santaball:santa_ball` сохранены.

## Установка

1. Полностью остановить сервер.
2. Убрать предыдущий JAR SantaBall/Santaball из plugins. Не оставлять две версии.
3. Положить `Santaball-1.4-Leaf-1.21.11.jar` в plugins.
4. Сохранить существующую папку `plugins/Santaball` с config.yml и cooldowns.properties.
5. Запустить сервер. ZIP с исходниками в plugins не нужен.

Выдача: `/santaball give НИК`. Себе: `/santaball`.
Перезагрузка настроек: `/santaball reload`.
Права: `santaball.give`, `santaball.reload`; по умолчанию у OP.
Активация: шар во второй руке, одно нажатие SHIFT; рядом нужен другой игрок
в Survival/Adventure в разрешённом радиусе. В мире с выключенным PVP не активируется.

## Изменения

- Текстуры предмета, голов Санты и подарков через Paper PlayerProfile API.
  Плагин не скачивает файлы или код с внешних серверов.
- NPC передаются пакетами протокола 1.21.11; нет AI или реальных игроков NPC.
  Профили скрыты в TAB, имена спрятаны отдельной клиентской командой scoreboard.
  Реальные scoreboard-команды сервера не изменяются.
- NPC появляются и у наблюдателей, подошедших во время эффекта; при уходе удаляются.
- Лавина бьёт в месте видимого падения после окончания периода слежения,
  а не телепортирует удар к убежавшей цели. Смена мира/выход цели отменяют лавину.
- Владелец не получает собственный урон, замедление и отбрасывание.
- Отмена урона другим плагином предотвращает дополнительные боевые эффекты.
- Декоративные подарки нельзя подобрать игрокам, мобам и воронкам;
  экипировка декоративных стоек защищена.
- Временные сущности, NPC и задачи удаляются при завершении/выключении.
- Кулдаун сохраняется при активации и выключении; файл записывается через замену.
- Конфигурация и прежние предметы сохраняются. Старые выданные головы без текстуры
  сохраняют способность; для новой текстуры выдать новый предмет командой.

`profile-cache-ticks` из старого конфига больше не используется: профиль NPC
сохраняется до конца эффекта с `listed=false`, чтобы скин успел загрузиться.
Нагрузка ограничена прежними лимитами количества эффектов/сущностей.

Целевая версия — 1.21.11. Версии 1.21.1/1.21.4 не поддерживаются этим JAR.
Используется внутренний протокол сервера, поэтому другие версии требуют сборки.
Для внешнего вида текстур клиенту нужен доступ к textures.minecraft.net.

## Сборка исходников

Нужны Python 3, JDK 21 и уже запущенный хотя бы один раз Leaf 1.21.11.
Указать серверный JAR из каталога versions (не загрузчик server.jar),
а также каталог libraries этого сервера:

```
python3 build.py --server /path/to/versions/1.21.11/leaf-1.21.11.jar --libraries /path/to/libraries
```

Результат — build/Santaball-1.4-Leaf-1.21.11.jar.
